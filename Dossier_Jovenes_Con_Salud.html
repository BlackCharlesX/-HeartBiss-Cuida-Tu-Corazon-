1. Grado de Innovación Tecnológica

El proyecto trasciende las aplicaciones convencionales de nutrición o conteo de pasos al consolidar un ecosistema sociosanitario bidireccional y predictivo con cuatro diferenciales de alta novedad:

1. Telemetría Wearables & BLE
Sincronización nativa con smartbands y glucómetros mediante @capacitor-community/bluetooth-le para ingesta continua de signos vitales (presión arterial, SpO2, glucosa, frecuencia cardíaca, sueño).
2. Detección Preventiva de Anomalías
Algoritmos bioestadísticos que cruzan variables fisiológicas en tiempo real y disparan alertas tempranas ante umbrales de prediabetes, crisis hipertensivas o fatiga crónica.
3. Arquitectura Offline-First
Almacenamiento local mediante IndexedDB y cola de sincronización automática en segundo plano (offlineSync), garantizando operatividad en comunidades rurales sin cobertura.
4. Expediente y Receta Electrónica PDF
Motor normado que compila antecedentes heredofamiliares, cirugías, alergias y telemetría, generando reportes clínicos y recetas médicas firmadas digitalmente con validación legal.

2. Claridad y Pertinencia del Problema Social

En el Estado de Tamaulipas, las enfermedades crónico-degenerativas no transmisibles representan la principal causa de mortalidad y saturación hospitalaria. Los datos epidemiológicos oficiales (ENSANUT, INEGI, ENDUTIH) sustentan la necesidad urgente de esta solución:

  • 75.0% de los adultos tamaulipecos presentan sobrepeso u obesidad.
  • 40.0% de los adolescentes (12 a 17 años) sufren sobrepeso u obesidad temprana.
  • 18.3% de prevalencia de Diabetes Mellitus Tipo 2 (una de las tasas más altas del país).
  • 30.0% de prevalencia de Hipertensión Arterial.
  • Causas #1 de Muerte Estatal: Enfermedades isquémicas del corazón y complicaciones diabéticas.

6.1. Algoritmo de Detección de Anomalías Clínicas

Archivo: server/src/utils/healthLimits.js

export const HEALTH_LIMITS = {
  bloodPressureSystolic: { min: 70, max: 200, normalMin: 90, normalMax: 120, unit: 'mmHg' },
  bloodPressureDiastolic: { min: 40, max: 130, normalMin: 60, normalMax: 80, unit: 'mmHg' },
  heartRate: { min: 40, max: 220, normalMin: 60, normalMax: 100, unit: 'bpm' },
  bloodGlucose: { min: 40, max: 400, normalMin: 70, normalMax: 100, unit: 'mg/dL' },
  spo2: { min: 70, max: 100, normalMin: 95, normalMax: 100, unit: '%' }
};

export function checkHealthAnomalies(record) {
  const anomalies = [];
  if (record.bloodPressureSystolic > 140 || record.bloodPressureDiastolic > 90) {
    anomalies.push({
      metric: 'bloodPressure',
      severity: record.bloodPressureSystolic >= 180 ? 'critical' : 'warning',
      message: 'Presión arterial fuera de rangos normativos de referencia.'
    });
  }
  if (record.bloodGlucose && (record.bloodGlucose < 70 || record.bloodGlucose > 140)) {
    anomalies.push({
      metric: 'bloodGlucose',
      severity: record.bloodGlucose > 200 || record.bloodGlucose < 55 ? 'critical' : 'warning',
      message: 'Nivel de glucosa en sangre fuera del rango óptimo.'
    });
  }
  if (record.spo2 && record.spo2 < 92) {
    anomalies.push({
      metric: 'spo2',
      severity: 'critical',
      message: 'Saturación de oxígeno por debajo del 92% (hipoxemia).'
    });
  }
  return anomalies;
}

6.2. Motor de Gamificación y Rachas de Salud

Archivo: server/src/utils/streakUtils.js

export function calculateStreak(lastDate, currentStreak = 0) {
  const today = new Date();
  today.setHours(0, 0, 0, 0);

  if (!lastDate) return { streak: 1, isNewDay: true };

  const last = new Date(lastDate);
  last.setHours(0, 0, 0, 0);

  const diffDays = Math.round((today.getTime() - last.getTime()) / (1000 * 60 * 60 * 24));

  if (diffDays === 0) return { streak: currentStreak, isNewDay: false };
  if (diffDays === 1) return { streak: currentStreak + 1, isNewDay: true };
  return { streak: 1, isNewDay: true, broken: true };
}

6.3. Sincronización en Segundo Plano (Offline-First)

Archivo: client/src/services/offlineSync.js

import { getOfflineQueue, clearOfflineQueue } from './offlineDb';
import api from './api';

export async function synchronizePendingData() {
  if (!navigator.onLine) return { synced: 0, pending: true };

  const queue = await getOfflineQueue();
  if (!queue || queue.length === 0) return { synced: 0, pending: false };

  let successCount = 0;
  for (const item of queue) {
    try {
      if (item.type === 'HEALTH_RECORD') {
        await api.post('/health/records', item.payload);
        successCount++;
      }
    } catch (err) {
      console.error('[OfflineSync] Error sincronizando elemento:', item.id, err);
    }
  }

  if (successCount === queue.length) await clearOfflineQueue();
  return { synced: successCount, pending: false };
}
